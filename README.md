Nowe projekty umieszczaj w `projects/nazwa-projektu/` z krótkim `README.md`. Oddzielaj pliki do pobrania (`downloads/`), instrukcje (`docs/`), podgląd (`preview/`) i ilustracje (`assets/`). Podawaj rewizję i zaznaczaj, czy model został sprawdzony fizycznie.

Przed drukiem zachowaj skalę 100%, dobierz profil własnej drukarki i przeczytaj instrukcję konkretnego projektu. Prototyp nie oznacza potwierdzonego pasowania.
