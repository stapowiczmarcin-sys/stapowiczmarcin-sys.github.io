Smart RGB Lamp

A handmade lamp built from reclaimed metal supports, painted and lacquered, with one 137-LED addressable strip split in software exactly like the real build: 100 LEDs in the main body and 37 LEDs in the plume.

Ręcznie wykonana lampa z odzyskanych metalowych elementów, pomalowanych i polakierowanych. Jeden pasek 137 LED jest podzielony zgodnie z prawdziwą konstrukcją: 100 LED w głównej części i 37 LED w pióropuszu.

Real LED geometry

LED 0–99 = BODY (100)

LED 100–136 = PLUME (37)

TOTAL = 137

One data line. The plume is not treated as an extension of the vertical body.

Features

  • Local web control at lampa.local
  • OLED 128×64 status display
  • OTA wireless updates
  • SinricPro / Alexa-compatible control
  • Separate body and plume brightness
  • Static, Comet, Rainbow, Sparkle, Dual, Breathe, Fire and Aurora effects
  • Independent plume modes: Sync, Complement, Pulse and Spark
  • Fast startup animation designed around the real 100 + 37 geometry

Wiring / Połączenia

OLED: SDA = D5, SCL = D6 • NeoPixel data: D2 • LED count: 137.

These values follow the current lamp code. Power supply sizing and grounding must match the actual LED strip and controller wiring used in the build.

Setup

  1. Install Adafruit NeoPixel, Adafruit GFX, Adafruit SSD1306 and SinricPro libraries.
  2. Open the downloaded sketch.
  3. Replace only the Wi-Fi, Sinric and OTA credential placeholders.
  4. Upload to the board.
  5. Open http://lampa.local on the same network.
  6. Use the web panel for effects, body brightness and plume brightness.
