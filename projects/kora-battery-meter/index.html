Start / Uruchomienie

Install Adafruit GFX + Adafruit ILI9341. Set the actual SHUNT_OHMS value; default 0 disables current measurement. Upload, compare with a multimeter, then join Wi-Fi KORA-Meter / KoraMeter1 and open http://192.168.4.1.
Wpisz rzeczywisty bocznik modułu, wgraj kod i sprawdź multimetrem. BACK 1.5 s resets totals; reboot also clears them.

A proper capacity test needs a rated external load with independent low-voltage cutoff. Choose limits from the actual cell documentation.
Pełny test pojemności wymaga obciążenia z niezależnym odcięciem. Ten kod nie odłącza ogniwa.
