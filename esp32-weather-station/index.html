ESP32-C3 · 2.8″ TFT · REAL BUILD

Weather station first. Retro arcade second.

A desk display built around an ESP32-C3 Super Mini and a 240×320 TFT. The practical part shows the weather at a glance; the fun part turns the same hardware into a small retro-game machine.

ESP32-C3 Super Mini240×320 TFT3-day forecastRotary encoderRetro games

What the display does

The interface is intentionally visual: the information that matters on a desk should be readable without opening a phone.

☀️

Current weather

Large current temperature with an animated weather presentation rather than a dense dashboard.

📅

3-day forecast

A separate forecast screen gives the next three days instead of squeezing everything onto one view.

💨

Weather details

Wind, humidity and pressure get their own readable information screen.

🕒

Large clock

The display can become a simple desk clock when forecast details are not needed.

🎮

Retro games

The same encoder and buttons are reused for small arcade-style games, so the project is useful even when the weather is stubbornly British.

📡

Network weather data

The weather functions use online forecast data. Private API credentials are deliberately not published in the project page.
