KORA · MASTER CONTROL · 16.09.2026

One control layer for six legs.

Kora Master Control brings the original Freenove motion mathematics, a Pimoroni Servo 2040 and a custom desktop remote into one controlled system. The goal is not to reinvent the gait: keep the proven XYZ trajectories and inverse kinematics, replace only the servo-output layer, then verify every stage on the real robot.

Verification rule: a successful compile is CODE READY. USB communication is VERIFIED only after a real PING/PONG. Walking becomes WORKING only after Kora actually completes the movement on hardware.

Current state

Servo 2040 USB bridge

Raspberry Pi sees the RP2040 board in MicroPython FS mode. MicroPython 1.29.0 responds correctly and the custom bridge returned a real PONG to PING on 16 September 2026.

VERIFIED

Freenove motion engine

The original Freenove gait generator, XYZ foot trajectories, inverse kinematics and point.txt calibration remain the source of motion. The planned migration changes only the output layer from PCA9685 channels to Servo 2040.

INTEGRATED / TESTING

Desktop remote

A dedicated Kora Remote GUI provides large forward, backward, left, right, rotate, base and servo-off controls plus gait, speed, step-length and turn-strength settings.

CODE READY

Six-leg calibration

The remote now includes a calibration window for all six legs. Each leg exposes X, Y and Z with − / + adjustment in single units, immediate Freenove recalculation, reload of the last point.txt and timestamped backup before save.

Architecture

1 · Raspberry PiRuns the Freenove motion engine and Kora Remote GUI.
2 · Freenove control.pyCalculates calibrated XYZ trajectories and converts them to coxa, femur and tibia angles.
3 · USB bridgeCollects the 18 leg angles into a complete frame and sends them to the RP2040.
4 · Servo 2040Updates all servo targets as one frame at 50 Hz output timing instead of reproducing the old PCA9685 hardware layer.
