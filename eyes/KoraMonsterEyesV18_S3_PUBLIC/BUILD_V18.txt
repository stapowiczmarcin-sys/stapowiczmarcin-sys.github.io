Tests compare original output exactly and protect eyelids, sclera and pupils for both eyes across 54 poses × 6 colours per variant.
Existing servo/sleep functions and all embedded texture arrays were compared against their bases unchanged.
The human variant preserves the already-published 500 ms manual blink.
One shared RGB565 PSRAM framebuffer is retained. Added colour LUT: 512 B, no per-colour bitmap.
Host timing is a desktop diagnostic, not ESP32 FPS: optimized monster sample medians baseline ~0.624 ms/frame, original mode ~0.629, blue ~0.649.
Colour processing has a small measured host cost. Device FPS must be checked using STATUS fps/renderMs; unchanged device FPS is not claimed.
ADC pin configuration remains -1/-1. Dual sensor normalization/mean, 350 ms low-pass, 2% hysteresis, asymmetric adaptation and stale serial fallback are documented.
Package validation covers ZIP CRCs, folder/sketch matching names, source completeness, local links and SHA-256.
